# Likelion_DataThon_Project
멋쟁이사자처럼: 데이터톤 프로젝트
검색·바이럴 데이터로 설계한 Rextreme 성장 전략 제안서

# OverView
ReXtreme은 FITCULATOR의 첫 오프라인 스포츠 이벤트로, 브랜딩과 운영 실행력은 입증했지만
지속적인 확장을 위해서는 유입 채널, 바이럴 흐름, 차기 개최 지역에 대한 데이터 기반 판단이 필요했습니다.
이에 플랫폼별 언급량 데이터를 수집·시각화하고, 공공데이터를 활용해 차기 개최 지역 후보를 분석하여 성장 전략을 제안했습니다.

# 데이터 안내
- 기업 제공 데이터 및 대용량 원본 공공데이터는 보안 및 용량 문제로 저장소에서 제외했습니다.
- 분석에 사용한 일부 원본 데이터는 별도 관리했습니다.
